# Публикация дашборда в облаке

Два шага: сначала база, потом само приложение. Порядок важен — без базы
приложение запустится, но будет терять данные при каждом перезапуске.

---

# Часть 1. Бесплатная база Neon

Почему именно внешняя база: Streamlit Community Cloud стирает файлы приложения
при каждом перезапуске (а он происходит сам по себе — при обновлении кода, после
простоя, при обслуживании площадки). Локальный файл базы исчезнет вместе с
загруженными выгрузками и введёнными звонками. Поэтому данные держим отдельно.

Neon выбран вместо Supabase по одной причине: у Supabase бесплатный проект
засыпает после недели простоя и его приходится будить руками через панель. Вы
заходите в дашборд примерно раз в неделю — как раз на границе. Neon просыпается
сам за доли секунды.

## 1.1. Регистрация

1. Откройте [neon.tech](https://neon.tech) → **Sign up**.
2. Проще всего войти через тот же GitHub-аккаунт — кнопка **Continue with
   GitHub**. Отдельный пароль тогда не нужен.

## 1.2. Создание проекта

> **Важно про примеры ниже.** Везде, где встречается строка подключения, она
> показана схематично — с сокращениями вроде `ep-...neon.tech`. Это **не
> рабочее значение**: копировать нужно настоящую строку из панели Neon, а не
> текст из инструкции. Многоточие в адресе сервера — самая частая причина того,
> что приложение не стартует.

После регистрации откроется мастер создания проекта:

- **Project name**: `avito-dashboard`
- **Postgres version**: оставьте предложенную
- **Region**: выберите Европу — `Europe (Frankfurt)`. Чем ближе, тем отзывчивее
  дашборд.

Нажмите **Create project**.

## 1.3. Скопировать строку подключения

Сразу после создания Neon показывает блок **Connection string**. Строка
выглядит так:

```
postgresql://имя:пароль@ep-что-то-12345.eu-central-1.aws.neon.tech/neondb?sslmode=require
```

Скопируйте её целиком кнопкой копирования. Если страница закрылась — строка
всегда доступна на **Dashboard → Connection Details**.

Эта строка содержит пароль от базы. Не вставляйте её в письма, документы и
уж тем более в код на GitHub — только в поле секретов Streamlit (часть 2).

Править строку не нужно: приложение само подставит подходящий драйвер, в каком
бы виде ни был префикс — `postgres://`, `postgresql://` или
`postgresql+psycopg2://`.

# Часть 2. Приложение на Streamlit Cloud

## 2.1. Вход

1. Откройте [share.streamlit.io](https://share.streamlit.io).
2. **Continue with GitHub** → тот же аккаунт, где лежит репозиторий.
3. Streamlit запросит доступ к репозиториям — подтвердите. Для приватного
   репозитория это обязательно, иначе он не появится в списке.

## 2.2. Создание приложения

Нажмите **Create app** (или **New app**) и заполните:

- **Repository**: `nisergey8904-cyber/avito-dashboard`
- **Branch**: `main`
- **Main file path**: `app.py`
- **App URL**: часть адреса до `.streamlit.app` — например `avito-stats`.
  Это и будет ссылка для начальника.

**Не нажимайте Deploy сразу** — сначала секреты.

## 2.3. Секреты

В том же окне разверните **Advanced settings** → поле **Secrets**. Вставьте
туда четыре строки, подставив свои значения:

```toml
admin_password = "ваш-длинный-пароль"
viewer_password = "пароль-для-начальника"
db_url = "СЮДА_ВСТАВИТЬ_СТРОКУ_ИЗ_NEON"
```

Вместо `СЮДА_ВСТАВИТЬ_СТРОКУ_ИЗ_NEON` вставьте строку, скопированную в части
1.3. Целиком, вместе с `postgresql://` в начале и `?sslmode=require` в конце.
В готовом виде она выглядит примерно так (адрес и пароль будут ваши, без
многоточий):

```
postgresql://neondb_owner:npg_R7xK2mQw@ep-quiet-frost-a2b3c4d5.eu-central-1.aws.neon.tech/neondb?sslmode=require
```

Про пароли:

- `admin_password` — ваш. Даёт загрузку выгрузок, ввод звонков и настройки.
- `viewer_password` — начальника. Открывает только дашборд, без возможности
  что-либо изменить или загрузить.
- Пароли должны отличаться и быть длинными: ссылка публичная, её может открыть
  любой, кто её узнает. Не используйте пароли, которые применяете где-то ещё.
- `db_url` — строка подключения из части 1.3, скопированная как есть.

## 2.4. Запуск

Нажмите **Deploy**. Первая сборка занимает 2–5 минут: Streamlit ставит
зависимости из `requirements.txt`. Когда закончится — откроется окно входа с
полем «Пароль».

Проверьте оба пароля: под своим вы увидите четыре раздела в боковом меню, под
«зрительским» — только «Дашборд» и подпись «Режим просмотра».

## 2.5. Перенос данных

База в облаке пустая — локальные выгрузки в ней не появятся сами. Зайдите под
своим паролем в раздел **«Загрузка выгрузок»**, перетащите четыре файла Авито и
укажите аккаунты. Затем при необходимости внесите звонки.

На вкладке **«Настройки»** проверьте блок «База данных»: жёлтого
предупреждения про SQLite быть не должно — вместо него отобразится адрес Neon.
Если предупреждение осталось, значит `db_url` не подхватился: проверьте, что
секреты сохранены (кнопка **Save** в настройках приложения) и что приложение
перезапустилось после сохранения.

# Часть 3. Что дальше

## Ссылка для начальника

Отправьте ему адрес вида `https://avito-stats.streamlit.app` и «зрительский»
пароль. Ставить ничего не нужно, открывается в любом браузере, в том числе на
телефоне.

## Еженедельное обновление

1. Скачали выгрузки из Авито по каждому аккаунту.
2. Открыли дашборд под своим паролем → «Загрузка выгрузок» → перетащили файлы →
   указали аккаунты → «Импортировать».
3. «Звонки» → внесли фактические звонки за дни периода.

Данные лежат в Neon и никуда не пропадают. Динамика по неделям на дашборде
появится со второй загруженной выгрузкой.

## Обновление кода

Если в проект вносятся правки, достаточно отправить их на GitHub:

```bash
cd /c/Projects/stats2
git add -A
git status --short
git commit -m "Что изменили"
git push
```

Streamlit заметит новый коммит и пересоберёт приложение сам за пару минут.
Данные в Neon при этом не затрагиваются.

## Если вместо дашборда появился экран с ошибкой базы

Приложение проверяет строку подключения при запуске и пишет, что именно не так.
Частые случаи:

| Сообщение | Что делать |
| --- | --- |
| «В адресе сервера стоит многоточие» | В секреты попал пример из инструкции. Скопируйте настоящую строку: Neon → Dashboard → Connection Details |
| «Не указан адрес сервера базы» | Строка обрезана при копировании — вставьте целиком |
| «Остались слова-заглушки» | Не заменены `имя:пароль` на настоящие данные |
| «Не удалось подключиться» | Строка похожа на правильную, но сервер не отвечает: проверьте, что проект в Neon существует и не удалён, а пароль не менялся после копирования |

После правки секретов нажмите **Save** — приложение перезапустится само.

## Если приложение «уснуло»

Бесплатный тариф усыпляет приложение после нескольких дней без посещений. При
следующем открытии оно поднимается само за 30–60 секунд — начальник увидит
заставку с надписью о пробуждении. Это нормально и данных не касается.
